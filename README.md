## 📖 Project Overview

This project is a GUI-based Java application designed to evaluate the performance of various sorting algorithms. The application allows users to upload a dataset (CSV format), select specific numeric columns, and execute multiple sorting algorithms to measure and compare their execution times.

The primary objective is to identify the best-performing algorithm for a given dataset based on execution speed.

## ✨ Key Features

* **Dataset Management:**
    * Upload datasets in `.csv` format.
    * Parse and display available columns from the uploaded file.
    * *Note:* Sorting is restricted to numeric columns only.
* **Sorting Algorithms Implemented:**
    1.  Insertion Sort
    2.  Shell Sort
    3.  Merge Sort
    4.  Quick Sort
    5.  Heap Sort
* **Performance Evaluation:**
    * Measures the precise execution time for each algorithm.
    * Automatically identifies and highlights the algorithm with the shortest execution time.
* **User Interface:**
    * User-friendly GUI for file selection, column choice, and results display.
